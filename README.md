# Iris Flower Classification using Machine Learning

## Project Overview
This project implements a machine learning model to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

The classification is performed using the Random Forest Classifier algorithm from the Scikit-learn library.

## Internship
CodeAlpha Data Science Internship

## Objectives
- Understand and explore the Iris dataset.
- Perform exploratory data analysis and data visualisation.
- Train a machine learning classification model.
- Evaluate the model using accuracy and a classification report.
- Predict the species of a new Iris flower using its measurements.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The Iris dataset contains 150 samples and four measurement features:

- Sepal length
- Sepal width
- Petal length
- Petal width

The target variable contains three flower species:
- Setosa
- Versicolor
- Virginica

## Methodology
1. Imported the required Python libraries.
2. Loaded the Iris dataset.
3. Explored the dataset and checked for missing values.
4. Performed exploratory data analysis and visualisation.
5. Split the dataset into training and testing sets (80:20).
6. Trained a Random Forest Classifier.
7. Evaluated the model using accuracy, precision, recall, F1-score and a confusion matrix.
8. Tested the model using new flower measurements.

## Model Performance
- Algorithm: Random Forest Classifier
- Training samples: 120
- Testing samples: 30
- Accuracy: 90%

The model correctly classified 27 out of 30 test samples.

## Sample Prediction
Input measurements:
- Sepal length: 5.1 cm
- Sepal width: 3.5 cm
- Petal length: 1.4 cm
- Petal width: 0.2 cm

Predicted species: Setosa

## Conclusion
The Random Forest Classifier achieved 90% accuracy on the test dataset. The project demonstrates how machine learning can be used to classify Iris flowers based on their physical measurements.
